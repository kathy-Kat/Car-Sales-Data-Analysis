# 🚗 Car Sales Data Analysis | SQL & Power BI

## 🔍 Project Overview

This project explores a car sales dataset containing vehicle manufacturers, models, sales volumes, prices, vehicle types, and technical specifications.

The objective is to transform raw data into a reliable dataset for analysis and develop an interactive Power BI dashboard that highlights sales performance, pricing patterns, and differences between vehicle models and manufacturers.

The project follows an end-to-end data analytics workflow, from data quality assessment and SQL-based cleaning to exploratory analysis and business intelligence visualisation.

## 📌 Objectives

- Assess and improve data quality using SQL.
- Identify missing values, potential duplicates, inconsistent data, and unusual numerical values.
- Analyse sales performance across manufacturers and vehicle models.
- Compare vehicle prices and sales volumes across vehicle types.
- Explore relationships between sales and specifications such as horsepower and fuel efficiency.
- Build an interactive Power BI dashboard to communicate findings.

## 🛠️Tools & Technologies

- **MySQL** — data cleaning, quality checks, and exploratory analysis.
- **Power BI** — data modelling, KPI development, visualisation, and dashboard design.
- **SQL** — aggregation, filtering, grouping, and analytical queries.
- **GitHub** — project documentation, version control, and portfolio presentation.

## 💡 Key Analysis Areas

1. **Manufacturer Performance:** Compare total reported sales across manufacturers and identify leading brands.
2. **Vehicle Pricing:** Examine average prices and compare pricing across manufacturers, models, and vehicle types.
3. **Sales and Specifications:** Investigate relationships between sales volume, horsepower, and fuel efficiency.
4. **Vehicle Type Comparison:** Compare sales and pricing patterns across vehicle categories.
5. **Data Quality:** Document missing values, potential duplicates, validation checks, and cleaning decisions.

## 🔃 Project Workflow

1. Inspect and profile the raw dataset.
2. Identify data quality issues.
3. Clean and validate the data using SQL.
4. Perform exploratory data analysis using SQL queries.
5. Prepare the cleaned dataset for Power BI.
6. Develop an interactive dashboard.
7. Document key findings and recommendations.

## 📈 Expected Deliverables

- SQL scripts for data profiling, cleaning, validation, and analysis.
- Documentation of data quality issues and cleaning decisions.
- A cleaned dataset suitable for reporting.
- A Power BI dashboard highlighting key findings.
- A summary of insights and potential business recommendations.
